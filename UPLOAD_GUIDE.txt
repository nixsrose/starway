STARWAY GitHub Pages 배포본

1. 이 ZIP의 압축을 풉니다.
2. GitHub 저장소 첫 화면에 index.html과 게임 JS/CSS/PNG/version.json/.nojekyll을 업로드합니다.
3. audio 폴더에는 두 개의 MP3를 같은 이름으로 업로드합니다.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. 배포가 완료되면 Pages의 Visit site로 접속합니다.

상위 STARWAY_GitHub_Pages 폴더 자체가 아니라 그 안의 파일을 저장소 최상위에 올려주세요.
브라우저에서 ZIP을 첨부하는 것만으로는 실행되지 않습니다.
GitHub 공개 저장소/Pages는 기존 클로즈 베타 초대 권한을 이어받지 않습니다.

포함 기능: 스토리 1-1~7-3, 무한모드, 상점(게임 코인), 기록, 설정, 맵 에디터, 배경 커스텀, 드래그/페이지 배치, 백업/복원.
온라인 창작맵 공유·순위: 서버 미연결 상태입니다. 맵 JSON 전달/가져오기는 가능합니다.
실제 결제·토스 SDK·광고 SDK는 연결하지 않았습니다. 기존 사이트를 호출하지 않습니다.
서버/인증서/사용자 기록/개인 데이터는 포함하지 않았습니다.

새 주소에서는 기존 진행 기록이 자동 이전되지 않습니다. 원래 게임에서 백업 내보내기 후 새 주소에서 복원하세요.
음악 자동재생은 브라우저 정책에 따라 첫 화면 터치가 필요할 수 있습니다.
PC/휴대폰의 파일 직접 열기가 아닌 HTTPS 웹호스팅에서 실행하세요.

음악 출처와 라이선스 표시는 게임 옵션에 유지되어 있습니다.
버전: starway-1298af2f5bee.js

開発者モード / 개발자 모드
시작 메뉴의 맵 에디터는 기본으로 숨겨집니다. 옵션 → 개발자모드 켜기 → 비밀번호 입력 후 표시됩니다. 옵션 → 개발자모드 끄기로 다시 숨길 수 있습니다. 다시 실행하면 꺼집니다. 창작모드의 맵 제작 버튼은 변경하지 않았습니다.
비밀번호는 메뉴 노출 제어용이며 소스 코드 접근을 막는 인증 기능은 아닙니다.

개별 브라우저 안에만 저장된 수정 맵은 이 배포 파일에 자동 포함되지 않습니다.
